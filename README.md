# Data Science Portfolio

A collection of end-to-end data science projects covering supervised and unsupervised machine learning, exploratory data analysis, 
and business-focused problem solving. Each project folder includes its own detailed README, notebook, and (where applicable) visualizations.

## Projects

### [Customer Churn Prediction](./Churn_Rate)
Predicts customer churn using Logistic Regression and Random Forest, paired with a Tableau dashboard built from key EDA findings. 
Covers the full supervised learning workflow: data cleaning, feature exploration, model comparison, and evaluation.

**Tools:** Python, scikit-learn, Tableau

---

### [Customer Segmentation with K-Means](./Customer_Personality_Analysis)
Uses unsupervised learning (K-Means clustering) to segment ~2,200 customers by income and spending behavior, with no predefined labels. 
Includes outlier handling, feature scaling, the Elbow Method for choosing K, Silhouette Score validation, and business-readable cluster interpretation.

**Tools:** Python, pandas, scikit-learn, matplotlib

---

### [Spotify Artist & Streaming Analysis](./Spotify_Analysis)
Explores what drives artist streaming performance through a nine-model regression sweep. 
Highlights include catching data leakage from algebraically derived features, applying a log1p transform to correct severe target skew, 
and documenting a null result as a legitimate, well-reasoned finding rather than a failed outcome.

**Tools:** Python, pandas, numpy, scikit-learn

---

## About
This portfolio reflects a self-directed transition into data science and machine learning, built through structured daily practice, project-based learning, and a focus on methodological rigor — including honest reporting of negative/null results, not just successful ones.
